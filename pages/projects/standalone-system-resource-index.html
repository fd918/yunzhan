一、产品定位与处理入口

闲鱼电影票系统用于协助店铺完成用户咨询、截图识别、自动报价、订单创建、出票和取票码发送。客服处理问题时，先在【订单管理】查看订单状态和失败原因，再区分渠道出票、报价配置、客户端在线和闲鱼账号状态。

宣传边界

不得承诺“躺赚”、固定折扣、固定利润、固定出票率或“保证学会”。源文档中的销售表述只作为历史话术线索，不进入现行承诺。

二、报价、识别与出票

加价报价
在渠道预估出票价上增加固定金额，并可设置成交价上限；适合不熟悉不同院线价格的用户。
专业报价
可按省市、院线、影院、影厅、影片、座位和日期等因素配置，适合有票务经验和自有资源的用户。
截图识别错误
先确认座位与场次信息是否完整；可人工创建订单，或提交原图、识别结果和错误信息给客服。
出票失败
在【订单管理】查看失败原因，核对开场时间、渠道状态和价格上限；自动退款规则在后台设置中确认。
  • 报价前确认影院、场次、座位和张数，一个订单的可识别座位数以当前系统限制为准。
  • 手动出票时先向买家确认完整信息，报价并收款后再创建订单。
  • 出票时效和进价折扣受影院、场次和渠道影响，不向用户承诺固定分钟数或固定折扣。

三、客户端在线与消息同步

自动回复和订单处理依赖客户端持续在线。网络中断、电脑关机、服务器异常、关键词未命中或客服 ID 绑定错误，都可能导致消息不同步或不回复。

  1. 确认客户端正常运行且网络稳定。
  2. 核对客服 ID 与对应店铺绑定关系。
  3. 核对商品关键词和自动回复规则是否覆盖用户提问。
  4. 重新关联后重启客户端，再用非系统店铺账号做真实消息测试。
软件安全

安装被系统拦截时，不指导用户关闭杀毒软件或删除安全中心。应先核验安装包来源和签名，使用官方最新版，并由技术排查兼容性。

四、账号、店铺与授权

  • 同一后台可管理多个店铺，具体授权数量和席位费用以合同及后台为准。
  • 源文档建议单台电脑同时运行不超过 3 个客户端；服务器可运行数量取决于 CPU、内存和实际负载。
  • 授权时长可在同一后台账号下的店铺间转移，支持的最短时长和次数以当前产品功能为准。
  • 频繁切换账号或登录环境可能触发闲鱼安全认证；不得尝试绕过平台验证。

五、充值、收款与退款

预充余额入口在系统【个人中心】→【余额充值】。充值后按页面要求及时回填交易单号；超过有效时间或未到账时转客服人工核对，群内不得公开支付账号、身份证、银行卡等信息。

  • 停止推广需要退余额时，使用当期正式退款登记入口，到账时效以财务确认结果为准。
  • 闲鱼订单款通常在买家确认收货后进入对应收款账户；自动确认时间以闲鱼平台规则为准。
  • 系统余额、营销工具余额和供应渠道资金必须分开核对，不混用退款入口。

六、运营活动与合规边界

鱼小铺、超级擦亮、返点和“放心充”等均受闲鱼官方资格、代理商政策及账号状态影响。源文档包含旧的充值门槛、返点比例、税点、席位价格和开通条件，全部标记为待产品与财务确认。

禁止不合规运营

不得用虚假低价、不出票、诱导确认收货、规避平台风控或收集超出必要范围的个人信息来提高权重。账号申诉和授权必须按闲鱼官方流程操作。
