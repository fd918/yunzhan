链接、密令与推广物料全生命周期 SOP

统一新链接申请、白名单、PID、密令、二维码、换链、回收和数据验证的操作步骤。

一、新链接申请与报备

  1. 确认业务名称、用户版本、用户标识和推广方式；
  2. 判断业务是否支持自助取链、自定义密令、库存密令或必须商务报备；
  3. 需要报备时进入受控登记表，普通群只发送工单号和脱敏摘要；
  4. 商务完成白名单、推广位、PID、密令或链接分配；
  5. 客服发送新链接、生效时间、旧链接状态、推广限制和验证方法；
  6. 用户产生首笔数据后核对归因，确认闭环。

二、密令生命周期

标准链路

申请 → 查重 → 绑定推广位/PID → 审核 → 生效确认 → 首单验证 → 到期提醒 → 续期或回收 → 用户通知。

台账字段要求
基础字段业务、用户、密令词、申请主体、推广位/PID
时间字段申请日、生效日、到期日、提醒日、回收日
状态字段待申请、审核中、已生效、待续期、已失效、已回收
验证字段是否跟单、是否参与激励、首单时间、负责人

低产回收、续期门槛、UV/订单要求和支持批次会变化，必须引用当期通知，不能把旧门槛固化为永久规则。

三、链接失效与换链

  1. 检测不可访问、跳转异常、不跟单或官方通知失效；
  2. 确认影响是全部业务、单个会场、单批密令还是特定推广方式；
  3. 只有明确受影响的会场或物料需要更换，不做全业务推断；
  4. 商务和技术生成新链、覆盖绑定或切换兜底域名；
  5. 识别仍在使用旧链的用户，使用统一话术私聊通知；
  6. 验证新链可访问、可取券、可跟单并适配当期激励；
  7. 旧链停用状态、影响数据和封禁原因进入复盘。

四、限量链接、圆码与手工物料

  • 建立库存、领取人、渠道标识、分配时间、首单和回收记录；
  • 平台无法导入圆码时，按 UID/渠道标识从受控表格分发并登记；
  • 同一套圆码、H5、密令不得重复分配给多个客户；
  • 长期无数据时先确认通知和回收规则，再分配给有明确需求的用户；
  • 用户私下收到的物料必须回到台账查验，不能默认有效。

五、完成与关闭标准

  • 物料已生效且用户明确收到；
  • 旧物料状态已说明，不会继续误用；
  • 首笔订单或测试数据归因正确；
  • 活动批次和激励参与方式已核对；
  • 台账记录完整，问题和处理结果可追溯。
